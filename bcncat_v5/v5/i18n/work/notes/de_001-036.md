# DE notes — Barcelona Cathedral 001–036 (Yo Tours, 14 Nov 2026 edition), voice Katja

Self-check: `assemble.py --check … de` passes for all 36 (exit 0). Total 9,398 German words against 9,833 English words, 4.4 % shorter. The bridges file has 15 lines, one for each English bridge, in the same order and with the same keys. Each line starts "In dieser Kurzfassung" and has no more words than the English line. Sources: the German is translated from the English only. catedralbcn.org was checked once (WebFetch, home page). It has only CA, ES and EN versions and no German one, so the German names below are standard German church terms, chosen once and used the same way in every title, cue and bridge.

## Ambiguities in the English (how I resolved them)
- 010 "a pool inside its own small building, later rebuilt with eight sides": it is unclear whether the pool or the building became eight-sided. The German keeps it open: "ein Becken in einem eigenen kleinen Bau, später achteckig neu errichtet".
- 004 "this busy front": rendered as "reich verzierte Front", meaning visually busy, not crowded.
- 001 "a working church": rendered as "eine lebendige Kirche", a church in active use. 036 "the city's own" is rendered as "und sie gehört der Stadt".
- 036 "Go gently." is rendered as "Gehen Sie behutsam." This is a literal farewell. A warmer option is "Machen Sie es gut", but it drops the "gently".
- 018: the Toisó d'Or is masculine in German ("der Toisó d'Or"), following the Catalan "el Toisó".
- Conditional (ONSITE) sentences: the brackets that were dropped from @where still apply to these German sentences.

## Possible problems in the English (reported, not fixed)
- 031: the Pietat door is "built at the end of the 1300s", but its Pietà is attributed to Michael Lochner, who 020 says was in Barcelona from 1483 to about 1490. This may be correct, with the relief added a century after the door, but listeners may hear it as a contradiction. Worth checking the source wording.
- 007: the English spells the historian "Hanss". If that is deliberate for TTS, note that the German uses "Hanß", which Katja reads correctly.
