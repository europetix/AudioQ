# Spotify Camp Nou / FC Barcelona Museum: gap-filling fact base (second researcher, 14 Nov 2026)

This file adds to `FACTS_NOV2026.md`; it does not rewrite it. The method is the same as §0 there:
- WebSearch and WebFetch only, one page at a time, never in bursts. No curl, no browser, no CAPTCHA.
- Wikipedia is never used alone, and search snippets are never used as a source.
- Failed pages are logged and were not retried. No prices or hours.

Grades are the same: OFF / SEC / SNIP / WIKI. So are the verdicts: OK / HEDGE / LEGEND / UNVERIFIED / ERROR / DATED.
- **WebFetch returns a model summary**, so every "verbatim" quote is **as relayed**, and quotes over about 125 characters came back in pieces. **Re-check the exact wording on the page before air.**
- **Real Madrid's pages are graded OFF-RM**: official for Real Madrid's own account only.

The source keys are new to this file. [GO…] is FC Barcelona, [GP…] is another official body (Real Madrid, the Holy See, UEFA, RFEF, AC Milan) and [GS…] is secondary. Where a FACTS source is reused, its FACTS key is given ([O34], [S8] …).
